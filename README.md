# Home Assistant add-ons

Add this repository in Home Assistant: **Settings → Add-ons → Add-on Store →
⋮ → Repositories**, then paste:

```
https://github.com/diogopms/ha-addons
```

## Add-ons

| Add-on | What it does |
| --- | --- |
| [SolaX Proxy](solax_proxy/) | nginx in front of a SolaX inverter's web server, with a fixed `X-Forwarded-For` header |
